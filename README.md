# Red Violeta Ciberprevención

Plataforma gratuita de orientación sobre ciberacoso basada en inteligencia artificial, dirigida a menores, familias y centros educativos en España.

Los asistentes (AURA, CALMA, PUENTE y LEX) son sistemas de IA. No son profesionales de la psicología, el derecho ni el trabajo social, y no sustituyen a los servicios de emergencia (112).

Sitio web: https://www.redvioletaciberprevencion.es

## Desarrollo

Proyecto creado con Lovable y desplegado en Vercel, con backend en Supabase.

    npm i
    npm run dev
